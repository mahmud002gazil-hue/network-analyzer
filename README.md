# Network Analyzer 🔍

Tam özellikli ağ paket analiz uygulaması - Python, C#, C++ ile çoklu platform desteği.

## 🎯 Özellikler

- ✅ **Paket Yakalaması** - Gerçek zamanlı ağ trafiği yakalaması
- ✅ **Protokol Analizi** - TCP, UDP, HTTP, DNS, ICMP, HTTPS vb.
- ✅ **Gerçek Zamanlı Görselleştirme** - Canlı paket akışı izleme
- ✅ **Filtreleme** - Gelişmiş paket filtreleme seçenekleri
- ✅ **İstatistikler** - Ağ trafiği analiz ve raporları
- ✅ **Çoklu Arayüz** - GUI, CLI, Web
- ✅ **Çoklu Platform** - Windows, Linux, macOS
- ✅ **Çoklu Dil** - Python, C#, C++
